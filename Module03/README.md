<a id="task-effect"></a>
## Task Effect of index

- The output of the injection_demo.py is [here]()

- User input is inserted directly into the SQL code. If a user enters a standard name like "Customer 10", the resulting query is: "SELECT * FROM customer WHERE name = 'Customer 10';" — and everything works as expected. However, if the user enters "' OR 1=1 --" the query becomes: "SELECT * FROM customer WHERE name = '' OR 1=1 --';" — and as a result, the query might return all customers instead of just one

- If, instead, you use a placeholder (?), SQLite treats user input strictly as a value rather than as part of the SQL code. Even if a user enters "' OR 1=1 --", SQLite will look for a client whose name is literally equal to that string, and the OR 1=1 condition will not be executed
